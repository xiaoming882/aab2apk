# aab2apk

在 Android 设备上将 AAB 转换为已签名 APK。无需电脑、无需网络、无需 Termux。

---

## 功能

- **选择 AAB 文件** — 从任意目录选取 `.aab`
- **转换为 APK** — 一键完成打包、编译资源、签名全过程
- **导入 android.jar** — 提供资源编译所需的框架文件
- **导入签名密钥** — 支持 JKS / PKCS12 / BKS，导入一次永久复用
- **一键安装** — 转换完成后直接调起系统安装
- **转换历史** — 点击安装，长按弹出菜单（安装 / 分享 / 删除），重启不丢失
- **彩色编译日志** — 8 个阶段全过程可视化，可复制、可清空、可中止
- **Material You** — 动态取色，跟随壁纸
- **中英文自适应** — 根据系统语言自动切换
- **横屏不重载** — 全屏沉浸式，旋转不丢状态

---

## 使用步骤

1. 导入 `android.jar`
2. 导入签名密钥（推荐 BKS 格式，密码 ≤ 7 位）
3. 选择 AAB 文件
4. 点击「转换为 APK」
5. 点击「安装 APK」

---

## 限制

- 仅支持 universal 模式
- 仅处理 base 模块
- 仅适配 arm64-v8a
- BKS 密钥密码 ≤ 7 位
